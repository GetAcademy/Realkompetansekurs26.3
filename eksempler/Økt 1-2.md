# Økt 1-2 — Layout (Flexbox/Grid) + Intro JavaScript

Opptak: Kommer etter undervisningen

---

## Mål for økten

- Bruke Flexbox og/eller Grid til enkel layout
- Forstå hva JavaScript er og hva det kan gjøre
- Skrive og kalle en funksjon
- Endre siden med `getElementById` + `innerHTML`
- Koble en knapp til en funksjon med `onclick`

---

## Del 1 — Layout med CSS

### Hva er layout?

Problemet: elementer stablet loddrett som standard. Hva om vi vil ha dem ved siden av hverandre?

### Demo 1 — Flexbox

```css
.rad {
  display: flex;
  gap: 16px;
}
```

```html
<div class="rad">
  <div>Boks 1</div>
  <div>Boks 2</div>
  <div>Boks 3</div>
</div>
```

utforsk selv:

- `justify-content: center` / `space-between`
- `align-items: center`
- `flex-direction: column`

### Demo 2 — Grid

```css
.rutenett {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 16px;
}
```

```html
<div class="rutenett">
  <div>Celle 1</div>
  <div>Celle 2</div>
  <div>Celle 3</div>
  <div>Celle 4</div>
  <div>Celle 5</div>
  <div>Celle 6</div>
</div>
```

### Selvutforsking

eksperimenter og prøv egne verdier. Du Trenger ikke å forstå alt — se _hva som er mulig_.

> Ressurs: https://css-tricks.com/snippets/css/a-guide-to-flexbox/, https://css-tricks.com/complete-guide-css-grid-layout/

## Del 2 — Intro JavaScript

### Hva er JavaScript?

> HTML = kroppen. CSS = klærne. JavaScript = musklene.

JavaScript lar siden _reagere_ på brukeren.

### Skill 1 — Funksjon

Skriv dette i konsollen (F12) -> Console:

```js
function siHei() {
  console.log("Hei!");
}

siHei();
```

Poeng:

- `function` er nøkkelordet
- Navnet velger vi selv
- Parentesene `()` betyr "kjør nå"
- Koden i `{ }` kjøres når funksjonen kalles

### Skill 2 — `getElementById` og `innerHTML`

```html
<p id="output">Her er teksten</p>
```

```js
document.getElementById("output").innerHTML = "JavaScript endret dette!";
```

Prøv i konsollen på siden.

Poeng:

- `document` er hele siden
- `getElementById("output")` finner elementet med den ID-en
- `.innerHTML =` bytter ut innholdet

### Skill 3 — `onclick`

```html
<button onclick="siHei()">Klikk meg</button>
<p id="output"></p>
```

```js
function siHei() {
  document.getElementById("output").innerHTML = "Du klikket!";
}
```

### Demo 3 — Alle tre samlet (bygg steg for steg)

```html
<!DOCTYPE html>
<html lang="no">
  <head>
    <meta charset="UTF-8" />
    <title>Hilsen</title>
  </head>
  <body>
    <input id="navnInput" type="text" placeholder="Skriv navn" />
    <button onclick="visHilsen()">Si hei</button>
    <p id="output"></p>

    <script>
      function visHilsen() {
        document.getElementById("output").innerHTML = "Hei, " + document.getElementById("navnInput").value + "!";
      }
    </script>
  </body>
</html>
```

### Oppgaver


Lag en enkel applikasjon som viser et tall (vi begynner med 1) og to knapper for å enten doble eller øke med 1. Lage en funksjon show1() som viser start-situasjonen. I dette tilfellet skal begge knappene kalle show2():

```js
function show1() {
    document.getElementById('dinId').innerHTML = `
        <h1>1</h1>
        <button onclick="show2()">Øke med én</button>
        <button onclick="show2()">Doble</button>
    `;
}
```
---

## Vanlige feil

| Feil                   | Årsak                                             | Løsning                  |
| ---------------------- | ------------------------------------------------- | ------------------------ |
| Knappen gjør ingenting | `onclick="visHilsen"` uten `()`                   | Legg til parenteser      |
| Element ikke funnet    | ID stemmer ikke                                   | Sammenlign tegn for tegn |
| CSS layout virker ikke | Mangler `display: flex/grid` på foreldreelementet | Inspiser i DevTools      |

---

## Tips

- Hold JavaScript-demoen enkel — tre ting, ikke mer
- Les feilmeldingen i konsollen høyt: "Hva tror du den sier?"
- CSS-layout: kopier og endre verdier, ikke prøv å forstå alt
